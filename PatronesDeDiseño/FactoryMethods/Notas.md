# Factory Methods
Es un patrón de diseño creacional. 
Enfoque que permite crear objetos sin tener que especificar su clase exacta.
Define una interfaz o método para crear un objeto pero deja que las subclases decidan que van a instanciar.
Es una forma de delegar la decisión y mantener el código más flexible.

Pros:
Evitas acoplamiento fuerte
Principio de Responsabilidad unica
Principio abierto cerrado

Contras
Implementar una multitud de nuevas subclases
